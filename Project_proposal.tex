\section*{Problem Description}
Automated classification of two-dimensional brain MRI images is a challenging image-recognition task because different tumor categories can share visual
characteristics, while images vary in appearance and quality. Convolutional neural networks (CNNs) and vision transformers offer different approaches to
extracting image features. Evaluating these approaches requires considering both classification performance and computational cost, since improvements
in predictive performance may involve larger models or longer training and inference times.

This project investigates the classification of brain MRI images into four categories: glioma, meningioma, pituitary tumor, and no tumor. We will use
version 2 of the publicly available \href{https://www.kaggle.com/datasets/masoudnickparvar/brain-tumor-mri-dataset}{Brain Tumor MRI Dataset}, which contains 7,200 
images, to compare selected ImageNet-1K-pretrained CNN and vision transformer models under a shared experimental protocol. Our central question is how these 
models differ in classification performance, model size, training time, and inference latency when evaluated using the same audited data partitions. The study will
provide a reproducible comparison on this image benchmark. Because patient identifiers are unavailable, its findings will not establish performance on
independent patients or clinical populations.


\section*{Related Work}
\citet{mzoughi2020} developed a multi-scale 3D CNN for distinguishing low- and high-grade gliomas from volumetric T1-Gado MRI and examined preprocessing and 
augmentation effects. This differs from our four-class task, which classifies individual 2D images as glioma, meningioma, pituitary tumor, or no tumor. The study 
therefore provides CNN-based brain-MRI background but does not establish expected performance for our setting.

Residual learning and efficient scaling motivate the CNN comparators. \citet{he2016} introduced residual functions and shortcut-based optimization for deep 
networks, forming the foundation of the ResNet family. \citet{tan2019} proposed EfficientNet's compound scaling of depth, width, and input resolution, with 
EfficientNet-B0 as its baseline. These models provide complementary CNN comparators for classification performance and computational cost. For transformer 
comparators, \citet{touvron2021} demonstrated data-efficient DeiT training on ImageNet without additional external data, while \citet{liu2021} introduced Swin's 
hierarchical representations and shifted-window attention. These designs motivate evaluating DeiT-Small and Swin-Tiny.

\citet{reddy2024} compared fine-tuned vision transformers with ResNet-50 and EfficientNet-B0 using 7,023 MRI images across the four target classes. 
\citet{cakmak2025} compared eleven ViT-, DeiT-, and Swin-family models, including DeiT-Small and Swin-Tiny, on a separate 5,249-image dataset while measuring 
predictive performance and computational cost. Differences in datasets and experimental procedures prevent these findings from establishing an expected
ranking on our version-2 dataset.

\citet{yagis2021} studied Alzheimer's and Parkinson's MRI classification and showed that slice-level splitting can inflate accuracy relative to subject-level 
separation when related slices cross partitions. This supports explicit duplicate checks and cautious interpretation of generalization, without assuming that 
duplicate removal establishes patient independence. Our study will, therefore, compare classification performance and computational cost under a shared, audited,
reproducible protocol.

\section*{Proposed Work}
\setlength{\emergencystretch}{2em}
Inspired by these architectural developments, our project aims to compare pretrained ResNet-50, \mbox{EfficientNet-B0}, DeiT-Small, and Swin-Tiny
in classification performance and computational efficiency on the brain tumor dataset. We will explore the strengths and limitations of
models and identify trade-offs between predictive performance and computational cost. Although these foundational studies demonstrate
the models' capabilities on general image recognition tasks, their relative performance on the MRI dataset remains unknown. In our
experiment, ResNet-50 and EfficientNet-B0 represent convolutional architectures, while DeiT-Small and Swin-Tiny each represent global and
hierarchical attention-based architectures. All models will be initialized using ImageNet-1K-pretrained weights and fine-tuned on the
selected MRI dataset. The standard, non-distilled DeiT-Small configuration will be used. The original classification layer of each pretrained
model will be replaced with a new layer containing 4 output units, corresponding to glioma, meningioma, pituitary tumor, and no tumor.

Images will be resized to \(224 \times 224\) pixels and represented using three input channels. Normalization will follow the requirements
of each pretrained model. An augmentation policy of rotations, translations, and zoom transformations will be applied to training images.
We will use the dataset's existing training and test sets as the initial split, reserving 20\% of the training images for validation while
preserving class proportions. Duplicate images across sets will be checked before training. All models will use identical data splits,
the same number of hyperparameter trials, and three fixed random seeds.

\section*{Evaluation Metric}
Model performance will be evaluated on the held-out test set after hyperparameters and training checkpoints have been selected using the
validation set. Macro-averaged F1 score (macro-F1) will serve as the primary evaluation metric since it combines precision and recall while
assigning equal importance to all four classes. It is defined as
\[
\mathrm{Macro\text{-}F1}
=\frac{1}{4}\sum_{c=1}^{4}
\frac{2TP_c}{2TP_c+FP_c+FN_c},
\]
where \(TP_c\), \(FP_c\), and \(FN_c\) denote the numbers of true positives, false positives, and false negatives for class \(c\), respectively.

Overall accuracy will measure the proportion of correctly classified images. Class-specific precision and recall will provide further insight
into each model's performance. Specifically, precision measures the proportion of predictions for a class that are correct, and recall measures the
proportion of images belonging to that class that are correctly identified. A confusion matrix normalized by true class will illustrate
misclassification patterns across the four categories.

Each model will be trained using three random seeds and identical data partitions. Classification metrics will be reported as the mean and
standard deviation across these runs to shows variation due to training randomness.

Computational efficiency will be evaluated using the total number of model parameters, average training time per epoch, and average inference
time per image. These metrics measure model size, training speed, and prediction speed respectively. Runtime measurements will use the
same hardware, input resolution, and numerical precision, with a common training batch size and an inference batch size of one.
